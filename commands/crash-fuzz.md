1. Run it from the project root: `python3 "${CLAUDE_PLUGIN_ROOT}/cli/forge_crash.py" --root .`, adding `--target FILE:FUNCTION` for each function the person named (only those are then checked). It finds the boundary functions (JavaScript/TypeScript: exported functions; Python: route/view-decorated functions, `__all__`, handler/webhook/parse-like names, a first parameter `request` or `event`), infers an input shape from the fields each one reads, and calls it with messy values: undefined, null, NaN, wrong types, missing fields, empty and very long text, lone surrogates, text that is not JSON. Exit 1 means at least one crash.

Show the person the headline line as it is (for example `CRASH-CHECK: 3 handlers crash with unhandled errors: TypeError on a missing field ...`), then each CRASH in plain words: which function, which messy value, the error, the source line, and the shrunk repro input. `{"__undefined__": true}` is undefined and `{"__nan__": true}` is NaN.
